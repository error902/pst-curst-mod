PST Curst Mod

Version 0.2.0 — WeiDU mod for Planescape: Torment focused on Curst.

Components

  • Shimmer (Mortuary proof of concept) — Adds a ghostly apparition named Shimmer to the Southwest Preparation Room on the Mortuary 2nd floor (AR0202). Clicking her shows a short description; she does not respond.

Compatibility

  • Planescape: Torment (classic, patched)
  • Planescape: Torment: Enhanced Edition

Installation

  1. Extract the pst_curst folder into your game directory (the folder that contains chitin.key).
  2. Copy weidu.exe into that directory and rename a copy to setup-pst_curst.exe.
  3. Run setup-pst_curst.exe and follow the prompts.

Or install with Project Infinity / WeiDU Install Tool.

Recommended install order

  1. Official game patch (classic) or current EE patch
  2. Fixpack (classic: Qwinn’s PS:T Fixpack; EE: EE Fixpack)
  3. Other content mods (e.g. Unfinished Business)
  4. This mod
  5. Tweaks / UI last
